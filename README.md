# Venkat Pavan Kumar Basetty — Portfolio

Open `dist/index.html` in your browser. If you downloaded the ZIP, extract it first and open `index.html` inside the extracted folder. Keep the HTML, CSS and JavaScript files together.

## Make it yours

Edit `content.js` in a text editor. Save the file and refresh the browser after each change.

- **Projects:** Copy one object inside `projects`, separate the objects with a comma and update its name, description, tags and link.
- **Skills and achievements:** Add entries in quotes, separated by commas. For example, `skills: ['HTML', 'CSS']`. Empty lists stay hidden.
- **GitHub and LinkedIn:** Edit the matching URLs under `contacts`. The email address and phone link are also listed there.
- **Résumé:** Put `resume.pdf` next to `index.html` and set `resume: './resume.pdf'` to show the résumé link.

## First commit and GitHub Pages

1. Create a new GitHub repository named `portfolio` and open it in your browser.
2. Use **Add file → Upload files** (or **uploading an existing file** on an empty repository). Upload the files **inside** `dist` or the extracted ZIP, so `index.html` sits at the repository root.
3. Enter **Add first portfolio website** as the commit message and click **Commit changes**. A commit is a snapshot of those files.
4. Open **Settings → Pages**. Select **Deploy from a branch**, then choose **main** and **/(root)** and save.
5. When the deployment finishes, use **Visit site** on the Pages settings screen. To publish updates, upload the changed files and make another commit.
